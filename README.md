# Cafe & Restaurant Demand Forecasting MLOps

**Status: in progress**

## Project Goal
The goal of this project is to build an end-to-end production-grade MLOps pipeline for forecasting cafe and restaurant visitor demand. Accurate demand forecasting allows restaurant and cafe operators to optimize staffing schedules, inventory procurement, and reduce operational waste.

## Dataset Source
This project uses data from the **[Recruit Restaurant Visitor Forecasting](https://www.kaggle.com/c/recruit-restaurant-visitor-forecasting)** competition on Kaggle.

> **Note:** The dataset is not included in the GitHub repository due to file size limits and licensing terms. It must be downloaded separately from Kaggle and placed in the `data/` directory. See [data/README.md](data/README.md) for download instructions and required CSV files.
